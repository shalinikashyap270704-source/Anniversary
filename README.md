# Anniversary

A romantic and interactive 1st Anniversary web experience celebrating Didi & Jiju's journey ("Do Dhaage, Ek Kahaani").

## Features
- **Stage 1**: Countdown & Celebration Intro
- **Stage 2**: Security PIN Check (PIN: 3011) with playful Shagun QR Scanner Mascot & Ribbon Cutting
- **Stage 3**: Sibling Memory Vault & Video Vending Machine (Cassette selector & retro CRT video player)
- **Stage 4**: The Red Thread of Destiny (Interactive horizontal scroll timeline with 3D photo polaroids, birds landing, and Sacred Knot convergence)
- **Stage 5**: Sunset Beach, Sibling Letter dispatch delivered by birds in a heart formation, and Grand Anniversary Fireworks Finale with interactive floating balloons
- **Customizable Media**: Easily replace photos, videos, and music in the `public/` folder (`public/photos/`, `public/videos/`, `public/audio/`).

## Setup & Run
```bash
npm install
npm run dev
```
